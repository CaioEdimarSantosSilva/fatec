# ProdutosFirebase

App Android (Kotlin) com Firebase.

## Configuração

1. Crie um projeto no [Firebase Console](https://console.firebase.google.com/) e registre o app com o pacote `br.edu.fatecpg.appkotlin`.
2. Baixe o `google-services.json` e coloque em `app/google-services.json` (use `app/google-services.json.example` como referência). Este arquivo **não** é versionado.
3. Abra no Android Studio, que gerará o `local.properties` automaticamente.
