Quem Somos

Uma loja criada para leitores

A Vitrine Geek é um projeto acadêmico de loja virtual voltado para livros, HQs e mangás.

Sobre o projeto

Catálogo, compras e avaliações em um só lugar

O sistema foi desenvolvido em Django para a disciplina de Desenvolvimento Web III. A proposta é simular uma loja virtual com cadastro de produtos, controle de estoque, histórico de compras e avaliações salvas no Firebase.

A loja também utiliza a Google Books API para exibir sugestões relacionadas ao tema.
